# FM X-Ray

Personal, read-only scouting tool for Football Manager 26 (FM27 later): reads a
career save and shows the whole player database, including CA, PA and hidden
attributes.

Status: design phase, no code yet. Project wiki: [wiki/index.md](wiki/index.md).

Unofficial fan project, not affiliated with Sports Interactive or SEGA. This
repository contains code only: no game data, no save files.
