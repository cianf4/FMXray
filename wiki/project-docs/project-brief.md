# Project brief

**FM X-Ray** è uno scouting tool per Football Manager 26 (poi FM27). Legge un file
di salvataggio e mostra tutto il database dei giocatori con più dati possibili,
compresi quelli che il gioco nasconde: current ability (CA), potential ability
(PA) e attributi hidden.

- **Perimetro:** uso personale, single player, sola lettura. Niente editing,
  niente overlay nel gioco. Si distribuisce solo codice.
- **Funzioni di base:** ricerca con filtri, tabella ordinabile, scheda
  giocatore, export CSV.
- **Poi:** rating per ruolo con pesi modificabili, proiezione degli attributi,
  storico tra salvataggi, rilevamento dei newgen, asking price stimato.
- **Alla fine, se serve:** lettura dalla memoria del gioco aperto.
