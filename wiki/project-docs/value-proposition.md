# Proposta di valore

## Motivazione dichiarata dall'utente

Non dipendere da tool esterni (closed source, solo Windows, legati alla RAM o a
build precise) per vedere i dati nascosti del gioco.

## Ipotesi da verificare (non ancora supportate da codice)

| Rispetto a | Possibile differenza |
| --- | --- |
| web app di fmsave | dati persistenti, storico tra salvataggi, pesi dei ruoli modificabili, proiezioni |
| FMSuperScout | niente gioco aperto né plugin, funziona anche su Linux |
| Genie Scout | open, export libero, pesi trasparenti, funziona anche su Linux |

Vedi [prior art](../reference/prior-art.md) e [evidenze](evidence.md).
